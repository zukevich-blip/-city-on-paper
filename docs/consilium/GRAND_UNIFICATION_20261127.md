## Порядок приёма любого модуля из архива (контракт)
1. Положить во временную папку, не в публичный путь. Указать происхождение, версию, лицензию (SPDX), автора.
2. Модуль без лицензии или с несовместимой не берём; изображения без подтверждённых прав остаются в исследовательском контуре.
3. Адаптировать под нашу книгу (лист → история → карта → интерьер → город → сейчас), без переноса чужого интерфейса.
4. Данные: только с источником; неизвестное остаётся «не установлено».
5. Тест на каждый модуль + `ruff`, `pytest`, браузерные проверки; запись в `docs/consilium`.
6. Один коммит на модуль, чтобы можно было откатить.

## Следующие шаги (после получения архива)
1. Описать содержимое архива: список модулей, лицензии, зависимости, размер.
2. Выбрать 2–3 модуля с наибольшей пользой для листа Бенуа (кандидаты: Allmaps-слой на листе, IIIF-лупа, мировая хронология).
3. Подключить по контракту выше, проверить, предложить к публикации отдельно.

## Пакеты V10 (15 модулей): решение
Все 15 без внешних зависимостей (кроме внутренних `tools/chronos`), лицензия в файлах не указана (автор: совместная работа с Gemini в этом проекте).
Берём по одному, после проверки: `museum-context` (принцип «неизвестное = null», у нас закреплён тестами), `benoist-catalog` (сопоставление оттисков, у нас делается в реестре), `computer-vision` (неразрушающие фильтры для крупного листа), `historical-cartography`/`temporal-system` (после сверки с `eras/`). Морфинг (`morphing`, 36 кадров) — только с пометкой «не совпадает перспектива».

## Этап 2 — исполнено
### 1. История места на странице листа (карта)
`book/app.js`: на карте листа (и на странице места) для Île de la Cité раскрывается панель «История места по годам»: ползунок эпохи (контуры OpenHistoricalMap, существовавшие в выбранный год), участки Вассеро 1810–1836, здания IGN сегодня, у каждого слоя своя прозрачность, лупа на плане 1878 (круг 90 px, работает пальцем), перечень «что исчезло» (контур без здания на этом месте сегодня по IGN; эвристика, не доказательство сноса), ссылки на Google Карты, Street View и Google Earth (обычные ссылки, данные не передаются).
Данные: `book/geo/cite-*.json`, сборка `tools/world/build_book_geo.py` из копий V10. Лицензии: ALPAGE ODbL (с атрибуцией «Arch. nat. F31 73-96 – Arch. Paris © ALPAGE»), OHM CC0, IGN Licence Ouverte 2.0. Высоты зданий из V10 **не берём** (реконструкция «13 м» без обмера). Тесты: `tests/test_book_geo.py`, `qa_book.js` (мобильные 320/390 и десктоп).
Ограничение: слои есть только для Île de la Cité; для остального Парижа остаются план 1878 и ссылки Google. Allmaps-слои `eras/` на листе не подключены (следующий шаг).
