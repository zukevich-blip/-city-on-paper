# Атлас ракурсов. Два прохода независимой экспертизы

Релиз-кандидат: PR #67 (ветка feature/viewpoint-evidence-atlas-20261113). Дата 13.11.2026.

**Метод:** независимые роли проверки требований, структуры данных, карты и UI, а не заседание внешних специалистов. Внешних людей, исследовательских учреждений и музеев не следует указывать как подписавших заключение. Каждое мнение ниже выводится из кода и доступных архивных сведений; окончательное научное утверждение геометрии требует живого картографа и полевых измерений.

## Исходный запрос посетителя

На всех уровнях: мировая карта → страна → город → исторический план → изображённый объект → работа → автор и позиция → направление взгляда → старое фото → актуальный вид → сравнение. Новая фотография должна быть геопривязана и появляться на карте без отправки с устройства. Исторические планы и фотографии доступны при смене масштаба. Не путать место объекта с позицией художника.

## Круг 1. Независимые замечания

| Роль | Позиция и найденный риск | Решение |
|---|---|---|
| Исторический картограф | Пиксельная позиция на плане относится к одному конкретному скану; перенос её на другие планы создаёт фикцию | Рисовать камеры по пикселям только на именованном фрагменте листа 1878, если совпадает image ID |
| GIS и геодезист | Исторические планы с приблизительными GCP не равны точной современной карте | Хранить остаточную ошибку/RMS и запрещать безусловное совпадение слоёв |
| Историк города | Современная улица может переместиться или исчезнуть | Разделить современный объект и исторический ракурс, атрибуцию отмечать отдельно |
| Историк искусства | Подпись автора, печатника, издателя, хранителя нельзя объединять в одно поле «автор» без оговорок | Подтягивать имена создателей из архивного оригинала; роль и источник смотреть в записи |
| Специалист по перспективе | Фокальная длина, высота художника и художническая условность неизвестны | Радиус неопределённости, азимут и уровень уверенности; ноль заявлений об «идеальном совпадении» |
| Фотограф-реконструктор | Фото того же здания не обязательно повторяет взгляд художника | Пары классифицировать как близкие, другие и без найденного современного кадра; показать карту |
| Архивист и специалист по правам | Архивная карточка и право публиковать полноразмерную работу различны | Для объектов с ограничением показывать только ссылку и данные; исходный лист не модифицировать |
| Специалист по музейному UX | Пользователь терял «где именно стоял» среди обычных меток | Отдельная экспозиция «Откуда смотрел автор» с двумя картами и паспортом |
| Мобильный UX/Safari | На iPhone карта и шторка могут конфликтовать с жестами, лист слишком мелок | Контролы минимум 44px, adaptive grid, отдельный скролл и проверка 390px |
| Инженер данных | «Каждой литографии современный аналог» не подтверждено коллекцией | Поля gap/status, не подставлять случайное фото ради 100% заполненности |
| Приватность | GPS фотографии может раскрывать адрес посетителя | Файл и координаты сохраняются в IndexedDB устройства; публичной загрузки нет |
| QA/red-team | Успешная отрисовка не доказывает, что переходы и сохранение работают | Playwright: выбор города, ракурсы, старый/современный план, загрузка и повторное открытие |

## Исправления после первого круга

1. Добавлен самостоятельный Viewpoint Atlas, отображаемый для каждого города, без подмены пустых позиций вымышленными.
2. Парижский план 1878 с точками Бенуа и исторических фотокамер показан только на соответствующем фрагменте листа. Точность координат оценочная.
3. Мировая современная карта показывает авторские камеры при уличном масштабе; мировая историческая карта отмечает географию городов, не камеры.
4. «Сравнить» указывает на совпадение изображённого объекта и уровень расхождения перспективы, а не насильственное наложение.
5. Фото посетителя связывается с выбранной работой, сохраняется на устройстве, имеет GPS/точку и направление. При наличии EXIF GPS читается локально; нет EXIF — ручной выбор на карте.
6. Существующий план города получает переход с метки объекта «место сегодня» и обратный переход «на старом плане», только при наличии исследовательских привязок.
7. Каталог без детальных доказательных ракурсов отображается как список задач по идентификации, а не как «полная фотовосстановленная выставка».

## Круг 2. Критерии приемки и незакрытые работы

| Направление | Условие зачёта | Статус |
|---|---|---|
| Историческая достоверность | Никаких придуманных GPS, авторов, геометрического совпадения | Код ограничивает; полевые измерения ещё нужны |
| GIS | Пиксельная позиция совпадает с именованным исходным листом | Ограничение реализовано; ГКП других карт отдельно |
| Архивная точность | Все права и атрибуции читаются из подтверждённых архивных записей | Ссылки сохранены; перепроверка тысяч работ остаётся |
| Пары «тогда и сейчас» | Фото относится к тому же объекту, а наличие/отсутствие честно показано | Реализован консервативный подбор; полное покрытие не достигнуто |
| Полевой режим | Пользователь загружает фото и выбирает где стоял/куда смотрел | Реализовано локально; следует проверить на реальном Safari |
| QA iPhone/desktop | 390/1440px, переходы, шторка, IndexedDB, без ошибок JS | Требует успешного CI с точным SHA ветки |
| Публичная безопасность | В очищенной сборке нет секретов, исследовательских неочищенных кандидатов | Требует проверки packaged/public CI |
| Внешний приём | Два цикла QA и человеко-ориентированная оценка скриншотов | Не выдавать за завершённый без фактических результатов |

**Вердикт:** продуктовая архитектура пригодна для тестового релиза после зелёного браузерного и пакетного QA на том же SHA, внешнего посещения GitHub Pages и подтверждения сохранения фото на настоящем iPhone. Научное подтверждение каждой камеры остаётся отдельной проверяемой записью. Не считать это формально подписанным экспертным заключением реальных независимых институтов.
