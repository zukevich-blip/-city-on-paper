# Мировой консилиум: City on Paper / 4 ноября 2026

## Как проводился разбор
Это **внутренний технический и редакторский консилиум по 14 профессиональным ролям**. Выводы сопоставлены с исходниками, ответами официальных музейных API и автоматическими тестами. Не проводилось собрание независимых привлечённых людей; Claude и Codex не запускались как внешние параллельные исполнители. Никаких выдуманных «отзывов пользователей» и «оценок экспертов».

**Один исходный проект:** `zukevich-blip/-city-on-paper`, ветка `release/city-on-paper-private-preview-20261104`, PR #31, задача #30. `main` и нативная старая Site v7 не переписываются.

## Консилиум ДО реализации: 14 контрольных взглядов

| Область | Вывод | Решение |
|---|---|---|
| Художественный куратор | 41 отобранная работа слишком мала, а произвольные тысячи карточек теряют смысл | 41 остаётся редакторским ядром, расширенные работы отдельно помечены как машинные находки |
| Историк Бенуа | Филипп, Феликс и другие Бенуа не должны смешиваться; период важнее ложной даты | сохранять имя мастера, дату из учреждения и проверяемую ссылку, неизвестное не заполнять |
| Историк архитектуры | эффектны реальные различия городской ткани и потерянные здания | дать маршрут «тогда/сейчас» и будущую коллекцию исчезнувших зданий, не дорисовывать доказательства |
| Куратор неевропейского искусства | европейская литография не охватывает японскую ксилографию и восточные техники | 150 поисковых направлений в 6 регионах; отдельная техника «Ксилография» |
| Географ / переводчик | подпись «город» по случайному результату поиска недопустима | проверка названия места в имени исходного файла, уровень доверия `title_mentions_city`, исходное название сохраняется |
| Специалист по авторским правам | возраст произведения не равен правам на цифровую копию | CC0, CC BY/SA и `public_domain_commons` показываются раздельно; LoC `no_known_restrictions` не CC0 |
| Архивист / библиотекарь | Commons часто воспроизводит работы иных музеев | первичный URL Commons и автор/правовой статус по карточке, хранитель может потребовать отдельной проверки |
| Технолог IIIF | AIC просит использовать /full/843 и допускает 1686 для PD, не произвольный 2000 | исправлен размер AIC до 1686; крупные файлы не скачиваются без нужды |
| Специалист по визуализации | бесконтрольная сетка поглотит художественное впечатление | атлас по шести регионам, страницы по 48 работ, поиск, тип техники, отдельная лупа для каждого листа |
| Исследователь истории города | ценность после первой минуты даёт вопрос, а не просто картинка | «Путешествие по пяти городам», возможность рассмотреть деталь, найти современную фотографию |
| Computer Vision | исторический и современный снимки одного здания могут иметь несовместимые ракурсы | сохранение реального ползунка в лаборатории, без выдачи некалиброванных пар за точные |
| Инженер производительности | много оригиналов размером 20–200 МБ замедлит любой iPad | лёгкие миниатюры, ленивое открытие, полный файл только по ссылке на источник, 41+178 локальных миниатюр в прежнем фонде |
| Инженер безопасности / приватности | домашний музей и фотографии семьи не должны попасть на публичный сервер | локальный HTTP по `127.0.0.1` по умолчанию; `--lan` только явное действие, без серверной загрузки личных фотографий |
| Инженер релиза и критик | несколько разрозненных сайтов создают иллюзию прогресса | одна выпускная ветка, единый ZIP, проверка реального пакета, состояние исходного Site v7 зафиксировано как НЕ перенесено |

## Фактическая архитектура одной версии
1. `data/curation/world-cities-v1.json`: **150 направлений поиска** в Европе, Азии, Африке, Северной/Латинской Америке и Океании. Это **не 150 городов с готовыми работами**.
2. `tools/curation/build_world_graphics.py`: ищет изображения в официальном Commons API, проверяет файл, владельца, тип, запись о правах, ставит уровень разрешения; не переносит неизвестные права в открытый фонд.
3. `data/curation/world-graphic-archive-v1.json`: создаётся проверяющей CI сборкой. Отделено от 41 вручную отобранной работы, 365 музейных API записей и современных фотографий.
4. `world/index.html`: мир как путешествие по регионам и городам, один из источников на каждом маршруте, пять случайных городов.
5. `salon/index.html`: одна галерея трёх фондов, качественное изображение/неизвестное разрешение, проверяемые авторы и лицензии, фильтры по технике, музею, региону, избранное и масштабирование 100–400%.
6. `photography/index.html`: отдельно современные фото с CC и автором. Даты загрузки Commons **не** заменяют даты съёмки.
7. `serve_local.py`: portable Python HTTP, по умолчанию только localhost, LAN только `--lan`. Исходники можно передавать IDE, Talos или агенту как обычную папку HTML/JSON; нативная интеграция Talos **не проверена**.

## Консилиум ПОСЛЕ реализации: ворота
Статус при написании: **полная мировая сборка ожидает CI**. До зелёного GitHub Actions и появления ZIP нельзя объявлять расширение готовым к пользованию. Каждое правило должно подтверждаться реальным пакетом, а не только source code:
- минимум 50 мировых работ из хотя бы 3 регионов (фактическое число и разрезы в `world-graphic-report.json`, а не обещанные тысячи);
- 150 поисковых направлений, 6 регионов в реестре, фактические города с изображениями показываются отдельно;
- нет изображений без правового статуса, CC BY/SA подписаны, `public_domain_commons` не выдано за CC0;
- проверены открытие `world/`, `salon/`, `photography/`, `closeup/`, `poc/compare/`, остальные 17+ маршрутов; картинки появляются и имеют fallback;
- тесты на 390px, 820px, 1440px: отсутствие горизонтального переполнения, доступность источников, zoom, просмотр исторического/современного;
- в ZIP есть `RELEASE_QA.json`, `VERSION.json`, `serve_local.py`, `PROJECT_HANDOFF.md`; файлы исходного Site v7 не объявляются перенесёнными;
- Safari/VoiceOver на настоящем iPad остаётся **NOT TESTED** до реальной проверки;
- полноценный публичный деплой/приложение остаётся **HOLD**, пока не определены защищённый хостинг, права и сохранение старого Site v7.
