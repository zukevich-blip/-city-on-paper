## 1. Какие инструменты уже были и чем полезны

**Исследовательский контур.** В прежних поисковых проектах применялись и обсуждались Exa (семантическая разведка источников), Firecrawl (извлечение и проверка публичных страниц), TinyFish (взаимодействие со сложными публичными сайтами). Все три сейчас доступны как подключённые инструменты. Не использовать массовые платные обходы и динамические браузерные задачи без расчёта выгоды и законности доступа; не трактовать поисковый результат как проверенное музейное описание.

**Разработка.** GitHub (репозиторий, PR, CI), Superpowers (рабочие методы и тестирование), Context7 (сверка API библиотек). Superpowers установлен, но это не хостинг и не автономный исполнитель Claude.

**Визуальная редакция.** Canva (подключена, создан редактируемый 8-страничный брендбук проекта и папка), Figma (UI-компоненты и макеты), MagicPath (быстрые варианты интерактивных прототипов). Canva не является источником правды о музейном предмете: её графика не заменяет подлинный оттиск.

**История и музейный материал.** LoC / Gallica BnF / Europeana и каталоги по первоисточникам; IIIF Image и Presentation, OpenSeadragon как технические стандарты/библиотеки, а не плагины ChatGPT. При упоминании "No known restrictions on publication" не переводить автоматически в "CC0".

## 3. Три полные схемы для проекта

### Схема A. Достоверный архив → сильная музейная история
`Exa/web` (обнаружить) → `Firecrawl`/API (извлечь доступную метаинформацию) → **оригинальная музейная карточка** (сверить источник, авторство, дату, инвентарный номер, права) → экспертное досье (архитектура, люди, политика, техника, издатель, нерешённые вопросы) → `GitHub PR` → `pytest + Playwright` → публикация.

**Обязательные поля каждой новой литографии:** архив/URL, стабильный ID, название на языке оригинала, атрибуция и роли, дата с диапазоном и уровнем уверенности, материалы/способ печати, цифровой файл и его статус использования, география, источники утверждений, причина неопределённости. Без подтверждения **никакого** объявления "Бенуа/1810/хромолитография/заказал Наполеон" по догадке.

**Практика:** продолжить от двух подтверждённых работ Бенуа в LoC к 10 хорошим досье. Наличие 1019 кандидатных записей не означает 1019 опубликованных или атрибутированных листов.

### Схема B. Хорошая история → интерес читателя → возвращение
Один документированный объект → короткая открывающая публикация (Canva 9:16/4:5, только лицензированное изображение) → `discover/` (90-секундная загадка с пятью точками) → выбор интереса (история, художник, путешествие, коллекция) → соответствующий раздел → сохранение своей заметки / ссылка другу.

**Аналитика только после запуска:** анонимные визиты, переходы к досье, завершение загадки, возвраты, процент обращений к архивному источнику. Пока нет реального публичного запуска и статистики, нельзя говорить "конверсия", "востребованность 30%", "монетизация подтверждена".

### Схема C. Город сегодня → личный архив → будущая общественная коллекция
Подлинный лист Бенуа + авторская современная фотография с указанной лицензией → посетитель выбирает памятник, добавляет **локально** собственный снимок → проверяет исторические признаки, дату, точку и права → записывает отличия → скачивает отдельное исследовательское JSON-досье без фотографии/GPS и PNG-сравнение для личного пользования.

**Что реально сделано:** `fieldwork/` для Мадлен и Пале-Рояль. Фото не отправляется на сервер, поля GPS не собираются; заметки хранятся только в браузере. Публикация чужих снимков и коллективная карта потребуют отдельной лицензии, согласия и проверки с модерацией.

## 4. Личный научный интерес: отдельная глубина

`printlab/` дополняет школу Барга `atelier/bargue/` и исторические орнаменты `ornaments/`. Техника печати показана как последовательность: жирный рисунок → обработка печатающих/непечатающих участков → смачивание → накатка краски → пресс → оттиск. Пользователь может добавить свою линию и сохранить PNG. В пояснениях отделены **ручная раскраска** и **хромолитография**: наличие цвета не даёт права предполагать несколько цветовых камней.

## 5. Рейтинг

Обновляемый локальный JSON `data/ideas/radar-20261103.json`, интерфейс `ideas/`. 14 идей, три схемы, пять весовых факторов: зрелищность 28%, глубина 25%, оригинальность 18%, готовность источников 19%, безопасность прав 10%. Оценка субъективная (0–10), **не измеренный рынок**.

**Первые направления для ресурсов:** 
1. Сделать 10 настоящих расследований Бенуа, подтвердив каждую архивной записью.
2. Проверить IIIF Deep Zoom на одном оригинале LoC или BnF.
3. Найти 3–5 совпадающих точек исторической/современной съёмки, без ложного перспективного наложения.
4. Создать контентный пилот 4 недели с реальными источниками, измерить удержание без сбора личных данных.
5. Сделать карту одной улицы по достоверному геопривязанному плану.
6. Вернуться к аудио только после проверки редакционного текста и произношения.

**Экономика:** платные альбомы/репродукции и коллаборации с экскурсоводами/издательствами пока гипотезы. Первым продуктом должно быть качественное открытое исследование, а не каталог товаров.

## 6. Проверяемое внедрение

Новые файлы этой ветки:
- `ideas/index.html` — живой рейтинг и схемы;
- `data/ideas/radar-20261103.json` — машиночитаемая модель и ссылки;
- `printlab/index.html` — учебная литографская симуляция;
- `fieldwork/index.html` — частное исследование с личной фотографией;
- `tests/test_idea_lab.py` и `tests/browser/qa_idea_lab.js` — права, пути, работа на разных устройствах, локальная загрузка/экспорт;
- навигация на главной, сборка и CI обновлены.

Не встраивались сторонние непроверенные скрипты и платные плагины. `main` и прежний ChatGPT Site не менялись. Следующий выпуск только после успешного CI и просмотра результатов на мобильном устройстве.
