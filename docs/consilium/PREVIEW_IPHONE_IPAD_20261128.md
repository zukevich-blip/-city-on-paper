# Предпросмотр нового музея для iPhone и iPad (ничего не опубликовано)

Основной сайт (`https://zukevich-blip.github.io/-city-on-paper/`) закреплён на проверенном коммите и не меняется. Новый музей — ветка `claude/grand-synthesis`, PR #104.

## Что готово
- Сборка: `python3 -m tools.release.build_public_site --source . --out /tmp/pubsite` (публичный комплект по белому списку, без исследовательских файлов). Вход нового музея: `/book/` (главная с галереей, залами, «Внутри истории»).
- CI собирает тот же комплект как артефакт `city-on-paper-vnext-preview` для каждого коммита ветки (раздел Actions → нужный запуск → Artifacts).

## Как открыть на телефоне без публикации
1. Скачать ZIP артефакта на компьютер, распаковать.
2. `cd <папка> && python3 -m http.server 8765` и открыть с iPhone/iPad в той же сети `http://<адрес компьютера>:8765/book/` (адрес: `ipconfig getifaddr en0` на macOS). Открывать по `http://` с адреса компьютера, не через `file://`.

## Варианты обычной ссылки (требуют вашего решения)
- **Отдельная ветка Pages.** У одного репозитория один сайт Pages, поэтому предпросмотр рядом с основным сайтом возможен только через отдельный репозиторий (например `-city-on-paper-preview`) со своим Pages. Нужно создать репозиторий и разрешить публикацию; публичная ссылка будет открыта всем, у кого она есть.
- **Внешний хостинг статики** (Netlify, Cloudflare Pages, Vercel): загрузка ZIP, ссылка вида `…netlify.app`. Нужен ваш аккаунт; платный биллинг не включать.
- Размер комплекта около 0,5 ГБ из-за изображений; для превью можно собрать облегчённый комплект (без полноразмерных изображений листов).

Ничего из этого я не выполнял: публикация, новый репозиторий и внешний сервис требуют вашего согласия.
