# Пилот агентов · 12 ноября 2026

**Стадия:** подготовка к реальному сравнению и тестовым изменениям; команды разных моделей не считаются реально запущенными, пока у каждой нет результата или журнала. GitHub-ветка для испытания: `review/safe-agent-consilium-20261112`.

## Принцип работы

1. Координатор: учитывает текущие PR, назначает один узкий участок работы, фиксирует baseline SHA.
2. Исследователь: проверяет источники. Статусы VERIFIED / INFERRED / UNKNOWN с датой.
3. Разработчик: создаёт изменения в отдельной ветке или существующем тестовом проекте, не ломает чужие PR.
4. Проверяющий: запускает тесты и независимо проверяет реальные ссылки/скриншоты/источники.
5. Экономист: сравнивает стоимость, расход лимитов и реальное время на одну подтверждённую задачу.

Пять ролей могут выполняться последовательно; нельзя считать их пятью отдельными ИИ-агентами без отдельных запусков.

### Критерии выбора
Достоверный результат 35 баллов, код и QA 30, защита данных 20, ресурсная эффективность 15. Без воспроизводимого результата оценка не выше 40 из 100; найденная уязвимость или ненужный доступ запрещает расширение прав независимо от суммы баллов.

### Ruflo: ограничение безопасности
В открытой истории Ruflo (ruvnet/ruflo, security issue #1375 и ответ разработчика в PR #1383) были проблемы с описаниями MCP, install-скриптами и механизмами очистки. В версии исходника 3.76.0 обнаружен исполняемый `postinstall` в пакете `@claude-flow/cli`, который изменяет файлы библиотеки `agentdb`. Это не доказательство вредоносности, но основание для теста без запуска install-скриптов, в эфемерном контейнере, без пользовательских токенов и без записи в рабочие репозитории. Никакой автоустановки на iPhone, Mac или VPS.

### Граница прав
Не использовать доступ ко всем сервисам только потому, что они есть в списке. Поднимать доступ по результату конкретной задачи; до этого разрешены чтение, изолированные ветки и безсекретные тесты. Никаких слияний в основную ветку, платных подписок, публикаций или отправки писем.

- **Основа:** `feature/engraving-museum-design-20261111`.
- **Задача:** Подтверждение первоисточников, качество мобильной экспозиции, карточки городов и доказательный реестр.
