# City on Paper — локальный архив и передача в TALOS / IDE

## Одна кодовая база
Рабочий исходник: `zukevich-blip/-city-on-paper`, выпускная ветка `release/city-on-paper-private-preview-20261104`, PR #31. Не создавать копии проекта для каждого редактора или ИИ-агента.

## Для использования на домашнем компьютере
1. Распаковать *весь* ZIP. На компьютере нужен Python 3. Открыть терминал в папке с `index.html`.
2. `python3 serve_local.py` (Windows: `py -3 serve_local.py`). Откроется `http://127.0.0.1:8765/`.
3. Для iPad/iPhone **в той же доверенной домашней Wi-Fi сети**: `python3 serve_local.py --lan`. Прочитать IP-адрес в терминале и открыть его в Safari. Не включать режим `--lan` в общественном Wi-Fi; он не защищён паролем.
4. Часть коллекции Cleveland доступна локально. Международные репродукции Commons, AIC и Met чаще остаются ссылками на официальные серверы, поэтому интернет нужен для полного фонда.

## Для Talos, Claude Code, Codex и других локальных инструментов
Передавайте весь распакованный каталог **как проект с файлами**. Полезные точки входа:
- `index.html` — главная; `salon/index.html` — каталог; `world/index.html` — мировой атлас; `photography/index.html` — фотографии; `poc/compare/index.html` — историческое / современное.
- `data/curation/*.json` — структурированные каталоги с источниками, датами и лицензиями; `world-graphic-archive-v1.json` — алгоритмический отбор, не музейная экспертиза.
- `assets/art/` — разрешённый локальный медиакэш; `RELEASE_QA.json` и отчёты — контроль количества и корректности.
- `CLAUDE.md`, `AGENTS.md`, `.claude/agents/` — рабочие инструкции агентов в GitHub (в ZIP не обязательны).
- `tools/curation/` — скрипты пополнения и проверки прав, исполнять только из исходного GitHub-проекта.

**TALOS:** этот пакет является стандартной локальной папкой HTML/JS/JSON. Специальной нативной интеграции в конкретную версию Talos пока нет; совместимость с возможностями импорта/индексации файлов требуется проверять для выбранного приложения. Это не самостоятельная установка iOS или offline AI.

## Уровни прав
- **CC0**: изображения, заявленные музеями или Commons как CC0.
- **CC BY / BY-SA**: автор, версия лицензии, ссылка на оригинал обязательны; для производных работ может требоваться share-alike.
- **public_domain_commons**: только утверждение Wikimedia Commons об общественном достоянии, **не** CC0. Перед публикацией/перепечаткой проверять страну использования.
- **loc_no_known_restrictions**: отдельная консультационная пометка Library of Congress, **не** CC0.

## О доверии
Машинная выборка работает по метаданным и названиям, не всегда безошибочно определяет место, технику и датировку. Система не утверждает, что нашла одинаковые точки съёмки исторического листа и современной фотографии. Старый Site v7 остаётся отдельным ресурсом, пока исходники не перенесены законно и корректно.
