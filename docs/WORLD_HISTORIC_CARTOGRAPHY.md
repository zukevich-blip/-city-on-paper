# World Historic Cartography / Глобальная картография

Статус: исследовательская ветка PR #46, создана поверх мирового реестра PR #45. Не сливать напрямую в публичный сайт. Парижская научная геопривязка PR #44 остаётся отдельной веткой.

## Реально доступные возможности

**Одинаковый интерфейс источников у всех существующих карточек городов:** `eras/cartography.js` и `eras/data/map-evidence.json`. Если карта установлена по записи музея, её карточка открывается напрямую в архиве. Если нет, отображается открытый поиск по картографической коллекции Library of Congress. Без архива, HD, прав и GCP не показывать выдуманный исторический слой.

**Проверенные архивные карточки на момент создания:** Париж 1878 (`2012586603`), Лондон 1853 (`2015591076`) и Рим 1944 (`map47000177`) в основной витрине. Дополнительно исследовательские записи Нью-Йорка 1870, Эдо/Токио 1853, Рио-де-Жанейро 1900 находятся в `data/research/global-city-historic-map-evidence-20261109.json`. У Нью-Йорка отдельно есть перспективная панорама Currier & Ives: её **нельзя геопривязывать как плоский план**. Для городов вне текущей витрины необходимо сначала пройти идентификацию и подключение, а не выдавать ссылку за опубликованную карточку.

**Мировая очередь картографических запросов:** `tools/maps/discover_loc_historical_maps.py` обрабатывает текущие 186 позиций атласа, 150 поисковых городов и при наличии отдельного файла кандидатов GeoNames города всего мира. Входные записи **могут дублировать один город**, пока не выполнено согласование GeoNames ID с каталогом. Поиск проходит только официальный `https://www.loc.gov/maps/?fo=json`, использует ограниченные партии и отрабатывает HTTP 429/503 и Retry-After. Полученная запись имеет статус `map_search_candidate_not_verified`, HD/IIIF/GCP/права не объявляются подтверждёнными.

**Охват основных городов мира:** `tools/maps/import_geonames_major_cities.py` использует ежедневный официальный справочник GeoNames `cities15000.zip`, порог 250 тыс. жителей по сведениям самого справочника плюс административные столицы. Координаты WGS84, устойчивые `geonameid`, ISO2 страны и численность позволяют сформировать большую географическую очередь. Реальная численность и география требуют выборочной проверки. Данные GeoNames доступны по **CC BY 4.0**, обязательно указывать GeoNames и ссылку, коммерческое использование при соблюдении лицензии допускается. Эти сведения **не** подтверждают расположение объекта на плане 1800 года.

```bash
# Вся очередь существующих и поисковых городов, без сетевых запросов
python -m tools.maps.discover_loc_historical_maps --dry-run --out /tmp/world-maps

# Реальное ограниченное обращение к оригинальному LoC Maps JSON API
python -m tools.maps.discover_loc_historical_maps \
  --out /tmp/world-maps --budget 18 --per-city 4 --delay 1.25

# Большие города мира из официального открытого справочника
python -m tools.maps.import_geonames_major_cities \
  --out /tmp/world-maps --min-population 250000 --max-cities 12000

# Составить объединённую НЕПРОВЕРЕННУЮ очередь поиска (без новых HTTP-запросов)
python -m tools.maps.discover_loc_historical_maps --dry-run \
  --out /tmp/world-maps \
  --geonames /tmp/world-maps/geonames-major-cities-research.json
```

Если официальный GeoNames/LoC временно недоступен, никакие искусственные записи и изображения не подставляются. Все исходные файлы и отчёты можно получить как артефакт GitHub Actions `worldwide-historic-map-research`, когда реальный запуск успешно сформировал их.

## Универсальный инструмент GCP

`tools/maps/fit_city_gcps.py` реализует локальную аффинную привязку **плоской** исторической карты любого города из заранее документированных пар пиксель ↔ WGS84. Требует минимум 4 неколлинеарные контрольные пары, поддерживает необязательные независимые holdout точки, считает тренировочный RMS, leave-one-out и holdout RMS, отклоняет дубли и недопустимую область координат. Все результаты обозначаются `research_only_manual_landmark_review_required`. Математически хорошее совпадение не доказывает, что пиксель здания выбран правильно.

Пример входного файла:

```json
{
  "city_id": "city-from-authoritative-gazetteer",
  "map_id": "archival-item-id",
  "image": {
    "source_url": "https://www.loc.gov/item/...",
    "width": 1000,
    "height": 800
  },
  "gcps": [
    {"px": 100, "py": 110, "lon": 2.3, "lat": 48.8},
    {"px": 750, "py": 120, "lon": 2.31, "lat": 48.8},
    {"px": 700, "py": 600, "lon": 2.31, "lat": 48.79},
    {"px": 120, "py": 550, "lon": 2.3, "lat": 48.79}
  ],
  "holdouts": []
}
```

Это только **схема формата**, искусственные координаты **не являются привязкой реальной карты**. Запуск:

```bash
python -m tools.maps.fit_city_gcps --input review_gcps.json --out research_fit.json
```

Старинные перспективные планы, панорамы, листы с локальной деформацией, полярные или протяжённые карты требуют других методов и экспертизы. Для карты с проверенной IIIF Image API можно использовать открытый формат **Allmaps Georeference Annotation**, GCP и маску картографической области. У hosted Allmaps API есть особые условия для коммерческого использования; не проектировать будущую монетизацию на предположении о бесплатном hosted tile proxy. Предпочитать открытые библиотеки рендеринга и самостоятельную инфраструктуру после оценки затрат.

## Строгий порядок привязки каждого крупного города

1. Географически идентифицировать населённый пункт из GeoNames/Wikidata и определить, не является ли запись названием района, достопримечательности или исторической неоднозначностью.
2. Найти подлинный план в LoC, Gallica, British Library и других национальных хранилищах. Установить датировку, автора, архивный ID и статус прав.
3. Проверить оригинальное изображение/IIIF и доступный масштаб. Не считать HTTP 200 достаточным доказательством доступности HD.
4. Подобрать 4–15 опорных деталей в старом и новом городе с одинаковой геометрической трактовкой. Отдельно проверить 2+ holdout точек, которые не участвуют в подгонке.
5. Рассчитать модель, показать остатки и маску, провести визуальную независимую проверку каждого сомнительного пикселя. Не принимать универсальную ошибку 20 м как годную для всех карт.
6. Сохранить экспертный протокол, версию исходных GCP, дату, точную картографическую опору и измеренное качество. Только после этого разрешить opt-in наложение и публичный статус `reviewed`.

## Ограничения

Год и разрешение снимка IGN для конкретного французского тайла отдельно не проверены; для других стран IGN вообще не является глобальной подложкой. OSM даёт улицы, а не собственный спутниковый слой. Фон на всемирной карте можно показывать по OSM с соблюдением политики tiles; массовая выгрузка плиток запрещена без договора. Нельзя смешивать перспективу старой гравюры и геодезическую сетку современного плана.

Публичное меню не показывает тысячи непроверенных геоназваний автоматически. Вначале идёт исследовательский импорт и идентификация, затем проверенные города постепенно включаются в существующий атлас. Публиковать 10 000 пустых карточек как 10 000 исторически изученных городов нельзя.

### Показатели прогресса, которые необходимо разделять

- `gazetteer_candidate_cities` (географические кандидаты);
- `archival_map_candidates` (подлинные найденные записи, но без оценки пригодности);
- `source_verified_maps` (оригинал, год, идентификатор, права);
- `georeferenced_research_maps` (математическая подгонка, качество);
- `expert_accepted_georeferences` (полноценная независимая приёмка);
- `published_map_layers` (доступны в публичном UI).

Не отождествлять эти стадии.

Источники: [LoC JSON API](https://www.loc.gov/apis/json-and-yaml/requests/), [GeoNames](https://www.geonames.org/export/), [Allmaps Docs](https://docs.allmaps.org/).
