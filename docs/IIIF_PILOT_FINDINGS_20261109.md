### Рабочий IIIF для исторического плана Парижа

- Картографический оригинал: *Paris et ses environs : 1878*, Эдуар Дюма-Ворзе, Institut géographique de Paris. https://www.loc.gov/item/2012586603/
- IIIF Manifest: https://www.loc.gov/item/2012586603/manifest.json — **1 Canvas**.
- IIIF Image API: https://tile.loc.gov/image-services/iiif/service:gmd:gmd5:g5834:g5834p:ct003569/info.json — **HTTP 200**, оригинал **15705 × 11378 px**, плитки 512 px, Image API 2.
- Исследовательская геопривязка уже имелась в `data/vision-lab/georef-paris-1878.json`: 15 пар пиксель ↔ WGS84, подготовленных предыдущей работой Claude по историческому листу и Wikidata/OSM. Это не независимая картографическая сертификация.
- Источник сообщает **аффинное RMS ≈25,9 м** и ошибку leave-one-out RMS ≈34,9 м. Эти числа *перенесены из исходных исследовательских расчётов*, не выданы за новое независимое измерение. Из-за неравномерного распределения опорных точек погрешность возрастает за пределами их области.
- На основании 15 точек построена черновая `data/research/paris-1878-georeference-draft.json` в формате **IIIF Georeference Annotation / Allmaps**. Маска ограничена выпуклой оболочкой точек, поэтому не притворяется точным планом всей территории и не захватывает весь лист с картами-врезками.
- Чтобы воспроизвести файл: `python -m tools.iiif.build_allmaps_annotation`. Для альтернативной версии используйте `--id` (реальный HTTP URL размещённого JSON).

**Статус:** корректная структура аннотации и ссылки на подлинный IIIF-сервис; практическое отображение наложения в Allmaps Viewer, Safari и на текущей карте Leaflet **ещё не проверено**. Самостоятельно открываемый публичный интерфейс на этом шаге не добавляется. Следующие ворота: ручная проверка GCP и границ маски, WebGL/Safari, браузерный тест и затем *интеграция в существующий экран города*, не новый прототип.

## Почему мы не геопривязываем сами литографии

Перспективный городской вид, подобный Мадлен, не является планом местности. Одна точка объекта не равна точке рисовальщика. Точки изображения `depicted_place`, `artist_viewpoint` и `photo_camera` должны оставаться независимыми сущностями. Для них не используется Allmaps 2D-картографическая трансформация без отдельного исследования проективной геометрии и ракурса.

## Приёмка перед слиянием PR

1. Положительный CI/Ruff/pytest на текущем SHA PR; проблемные тесты сначала исправить.
2. Проверить доступность raw JSON и Image API с браузера и реального iPhone Safari.
3. Проверить GCP вручную на оригинальной карте, особенно `low` и западную/северную периферию; записать, кто и когда подтвердил.
4. Протестировать импорт аннотации в Allmaps Viewer, проверить маску и центр карты. Не заявлять точность для здания или кадра, если есть только обзорный RMS.
5. Отдельно проверить оригинальные сканы и права; при отсутствии Image API показать архивный JPG с источником.
6. Только затем перенести проверенное в публичный каталог и добавить один контролируемый переключатель исторического наложения к существующей карте Парижа.
