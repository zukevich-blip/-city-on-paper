# Инвентаризация инструментов, skills и MCP (Issue #34) — 07.11.2026

Что **реально доступно** в этой сессии Claude Code (облачный контейнер, сеть через прокси), что использовано и что только оценено. Платные действия, передача приватных материалов и публикация без согласия владельца не выполнялись.

## Использовано в работе по #34

| Инструмент | Что делает | Где применён | Ограничения |
|---|---|---|---|
| Claude Code subagents (Agent tool) | независимые специалисты консилиума с собственным контекстом | картограф/GIS, архивный куратор и фото-ракурсы, frontend/GIS-tech, затем скептик/red-team | агенты — модели, а не люди-эксперты; их выводы перепроверялись |
| GitHub MCP | issues, PR, ветки, CI-логи | чтение #34, draft PR, отчёт | merge и Pages не трогались |
| Playwright + Chromium (локально) | браузерные тесты и скриншоты 390/820/1440 | QA прототипа, скриншоты направлений | **не Safari**: iPhone/iPad Safari и VoiceOver НЕ ПРОВЕРЕНЫ |
| Python: Pillow, NumPy, OpenCV 4.10 | обработка изображений, геопривязка (аффинная/полиномиальная), гомография | геопривязка плана, удаление EXIF у фото, QA | — |
| Публичные API архивов | LoC (`?fo=json`), Cleveland, AIC, Met, Europeana (демо-ключ), Panoramax, Wikidata | поиск карт, литографий, фотохромов, современных фото | Gallica напрямую 403, Wikimedia часто 429 — не обходилось |

## Доступно в сессии, оценено, НЕ использовано (нужно согласие или нет пользы сейчас)

| Подключение | Возможность для проекта | Почему не использовано |
|---|---|---|
| Figma MCP | редактируемые макеты дизайн-системы, экспорт в код | макеты сделаны HTML-кодом, этого достаточно для выбора; можно перенести по запросу |
| Canva MCP | открытки/постеры для будущего магазина | права на коммерческую печать не проверены по всем работам |
| Gamma | презентация для партнёров (музеи, школы) | не требовалась на этапе пилота |
| ElevenLabs | аудиогид: озвучка историй | **тратит кредиты владельца**; текст историй сначала должен пройти проверку историком |
| TomTom Maps MCP | геокодинг, пешие маршруты | лицензия TomTom ограничивает показ на сторонних картах; для маршрутов лучше OSM/OSRM — нужна отдельная проверка |
| Booking / Tripadvisor | связка «прогулка → где остановиться» | коммерческая интеграция без согласия не делается; партнёрства требуют раскрытия |
| Shopify | будущий магазин принтов | рано: сначала матрица коммерческих прав |
| Notion / Google Drive / Docs | редакционный план, общий доступ для кураторов | не нужен для кода; можно завести по запросу |
| Three.js viewer | 3-D сцены (например, «стол картографа») | WebGL-нагрузка не оправдана для мобильного музея |
| Vercel / Lovable / Base44 | альтернативный хостинг/конструкторы | проект уже на GitHub Pages; второй стек не нужен (Base44 требует авторизации) |
| Claude Docs / Artifacts | публикуемые страницы-отчёты | отчёт ведётся в репозитории и PR |
| Skills: `dataviz`, `artifact-design`, `code-review`, `security-review`, `deep-research`, `canvas-design`, `pdf` | визуализация, ревью, исследование, генерация PDF-путеводителя | `code-review`/`security-review` применимы на этапе PR; `pdf` — для будущего PDF-путеводителя |

## Недоступно

- **Codex, Gemini и другие внешние ИИ** — в сессии не подключены; их «мнения» не приводятся.
- Ticketmaster MCP — не подключился (ошибка соединения); для проекта не нужен.
- Miro, часть Adobe — отключились во время сессии.
- Реальные устройства iPhone/iPad — нет; Safari и VoiceOver: **НЕ ПРОВЕРЕНО**.

## Правило

Ни один инструмент не получает приватные фотографии владельца и не публикует данные. Любое использование платных кредитов (ElevenLabs, Gamma, Canva Pro), коммерческих API и публикации — только после явного согласия.
