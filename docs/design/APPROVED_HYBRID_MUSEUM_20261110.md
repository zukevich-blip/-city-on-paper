# Город на бумаге — гибридный музей, реализация после выбора направления

**Решение владельца:** 10 ноября 2026. **Принятый формат:** Книга как необязательный эффектный вход; Живой музей как основной интерфейс; Атлас времени как проверяемый исследовательский инструмент.

**Среда:** черновая ветка `feature/hybrid-city-museum-20261110`. Публичный сайт и `tools/release/build_public_site.py` не менялись.

## Что именно сделано

1. **Главная стала музеем историй**. Начало — Париж Филиппа Бенуа (LoC `2016652452`): большая литография без фильтров, читаемая редакционная аннотация, один главный переход в пятиглавную историю. Далее три тематических входа: Пале-Рояль, Флоренция, Неаполь. Каждый использует архивный оригинал с известными правами.
2. **«Атлас времени» (`atlas/`)** выделен в отдельную исследовательскую комнату с выбором города и исторического материала. Из `eras/data/eras.json` фильтруются реальные локальные изображения `rights_class=open`; карточки показывают архивный заголовок, датировку, художника, учреждение и прямой HTTPS-источник. Нет выдуманных картографических координат, легенд точности и «переезда зданий» из несовпавших ракурсов.
3. **Книга (`experience/`)** сохранена как отдельный факультативный маршрут. Возврат в обычный музей доступен без анимации, кнопка «Спокойный режим» уже существует и сохранена.
4. **Коллекция и кабинет** сохраняют предыдущие функции, код и данные. Новые ссылки ведут в существующие `#catalog`, `studio/`, `stories/`, `eras/`, `poc/compare/`. Личные данные не отправляются в облако: сохраняются локальные заметки и избранное согласно прежней реализации.
5. **Одна визуальная система**: `assets/hybrid/tokens.css` фиксирует пять цветов ранее существовавшей Canva-доски; `assets/hybrid/museum.css` задаёт редакционный главный экран; `stories/story.css` и `experience/styles.css` ссылаются на те же шрифтовые и цветовые токены; атлас использует их напрямую.

## Кураторский и научный протокол

- История **`Paris. La Madeleine`**: рисовальщик Philippe Benoist, типография Lemercier, датировка LoC 1845–1860, https://www.loc.gov/item/2016652452/.
- **Пале-Рояль**: Philippe Benoist, `Paris. Jardin du Palais Royal`, LoC 1845–1860, https://www.loc.gov/item/2016652451/.
- **Флоренция**: Joseph Pennell, `Ponte Vecchio, Florence`, офорт, 1883, Art Institute of Chicago https://www.artic.edu/artworks/194443.
- **Неаполь**: Calvert Richard Jones, `St. Lucia, Naples`, 1846, Art Institute of Chicago https://www.artic.edu/artworks/27086.
- Для остальных изображений атлас получает метаданные непосредственно из существующего `eras/data/eras.json`, не копируя чужую атрибуцию из случайного макета Canva.
- **Карта Европы 1769** — исторический объект Library of Congress https://www.loc.gov/item/97683588/. Она показывается как архивный документ **без формального GIS-совмещения**. Метрическая верификация по независимым GCP остаётся отдельным научным направлением (PR #54).

## Конкретный путь посетителя

```text
ЖИВОЙ МУЗЕЙ / Главная
  |
  | Главный CTA «Начать историю Парижа»
  +-> ИСТОРИЯ: пять глав -> оригинал LoC -> сравнить / сохранить
  |
  +-> ГОРОДА: Пале-Рояль / Флоренция / Неаполь
  |
  +-> АТЛАС ВРЕМЕНИ: выбрать город -> печать/фото/современный вид
  |       -> карточка подлинника -> права -> музейный оригинал
  |
  +-> КОЛЛЕКЦИЯ: старый сверенный каталог с избранным
  +-> МОЙ КАБИНЕТ: заметки и локальные находки
  +-> КНИГА ГОРОДОВ: опциональная анимация -> глава -> вернуться
```

## Обязательные критерии

- **Источник важнее анимации**: на главной до книги есть подлинное изображение и одна полноценная история.
- **Три разных пути**: в один клик доступны редакционная история, исторический атлас и каталог; книга ни одному из них не предшествует как обязательный шаг.
- **Новый код не пишет географические координаты** и не изобретает отсутствующие временные слои. Все атласные карточки связаны с реально присутствующими архивными URL.
- **Мобильный браузер 390 px, iPad 820 px, desktop 1440 px**. Browser QA проверяет отсутствие горизонтального скролла, переключение городов, техническую загрузку исторических изображений и работоспособность действий на упакованном ZIP.
- **Честная доступность**: тексты `alt`, реальные `button`, `aria-pressed`, `role=status`, `focus-visible`, `prefers-reduced-motion`, ссылки без JavaScript на истории и старый атлас.
- **Весь существующий каталог/новые кандидаты** остаются в исходном состоянии. Непроверенные объекты не объявляются опубликованными произведениями.
- **Без изменения публичного Pages**: сборка и проверка только из draft PR. Отдельный процесс релиза после визуальной приёмки, правового контроля и решения владельца.

## Дальнейшее развитие после проверки

1. Увеличение подлинников через IIIF там, где есть корректные манифесты и условия использования.
2. Более богатые 6–10 главные экспозиции о городской жизни, море, архитектуре, художнике, печати и ремёслах.
3. Кросс-связи между произведениями (художник — мастерская — техника — место — эпоха) с источниками и provenance.
4. Сохранение читательского прогресса **локально и с экспортом**, без заявления об облачной синхронизации.
5. Отдельная научная геопривязка карт: допускать геометки и геометрический slider только после независимых проверок и юридической верификации прав.

Это **реализованная исследовательская версия**, а не публичный релиз.
