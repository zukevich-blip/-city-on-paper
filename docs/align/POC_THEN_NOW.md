# Прототип «Тогда / Сейчас»: обратимое совмещение фото (Issue #6, PR B) — 01.11.2026

**Это независимый прототип, не выставка.** Он не трогает опубликованный сайт и не заменяет его. Когда исходник выставки восстановят (#1), просмотрщик встраивается отдельным PR (D) — в существующий код, а не вместо него.

## Правило целостности изображений

- **Историческое изображение не меняется.** В браузере у `<img>` литографии нет `transform` и `filter` — это проверяет QA-тест. В репозитории файл лежит байт-в-байт таким, каким скачан (`sha256` в `pair.json` проверяется в pytest).
- **Меняется только геометрия фото, и только при показе.** Матрица 3×3 `H` (пиксели фото → пиксели литографии) применяется к фото как CSS `matrix3d`. Файл фото не пересчитывается. Кнопка «Фото: оригинал» в один клик возвращает исходный кадр, плашка «Геометрия фото скорректирована · обратимо» видна всегда. Ссылки «открыть без изменений» ведут на оба полных файла.
- Генеративное заполнение, ИИ-дорисовка и перекраска не используются.

## Вердикты

Порог — относительно диагонали исторического изображения:

| Вердикт | RMS | Худший leave-one-out | Что показывает просмотрщик |
|---|---|---|---|
| `high` | < 0.5 % | < 1.5 % | совмещённое фото по умолчанию |
| `medium` | < 1.5 % | < 4 % | совмещённое фото и предупреждение |
| `low` | — | — | **по умолчанию оригинал фото**; попытка совмещения доступна по кнопке |
| `viewpoint_mismatch` | — | — | только оригиналы, кнопка совмещения неактивна |

Leave-one-out — это проверка параллакса. Гомография верна только для одной плоскости (фасада) или для чистого поворота камеры. Если точка, выброшенная из подгонки, плохо предсказывается остальными, значит в кадре несколько планов глубины или другая точка съёмки. Тогда честный ответ — «низкая уверенность», а не подогнанная картинка. Если контрольные точки покрывают меньше 15 % листа, совмещение помечается как **локальное**, и его контур рисуется поверх.

## Три условия съёмки (синтетика, правильный ответ известен заранее)

| Пара | Условие | Ожидалось | Получено | RMS / LOO max |
|---|---|---|---|---|
| `synthetic-near-identical` | камера почти не сдвинута | high | **high** | 2.95 px / 9.93 px |
| `synthetic-rotation-only` | та же точка, камера повёрнута и наклонена (исправимо) | high | **high**; `H` совпадает с точной `K·R·Rᵀ·K⁻¹` с точностью < 3 px | 0.82 px / 2.75 px |
| `synthetic-parallax` | камера сдвинута на 5 м, два плана глубины (фасад 30 м, киоск 15 м) | low / mismatch | **low** | LOO max 203 px |

## Одна реальная пара (кандидат, не «подтверждённая пара»)

**Philippe Benoist, «Paris. La Madeleine»** — Imp. Lemercier, [1845–1860], раскрашенная литография.
- Library of Congress, LC-DIG-pga-14315: https://www.loc.gov/item/2016652452/
- Права: «No known restrictions on publication» (проверено 01.11.2026).
- Файл — служебная копия LoC 1024 px, байт-в-байт.

**Фото:** Panoramax `38b6d262-648f-461e-b9a3-ab05eb22d92a`.
- Автор jerome92370, 30.04.2026, iPhone 15 Pro, азимут 21°, ~89 м до храма, **CC BY-SA 4.0**.
- Лица уже размыты Panoramax.
- Файл перекодирован один раз (JPEG q92) только для того, чтобы убрать EXIF/GPS. Исходный `sha256` записан.

**Результат:**
- 7 контрольных точек, все на плоскости южного портика: фронтон, концы карниза, капители и базы угловых колонн.
- Вердикт **medium**, но **только локально**: точки покрывают 7 % листа. RMS 6.55 px, LOO max 22.9 px, обратимость 0 px.

**Визуальная проверка Claude.** Фронтон, рельеф и восемь колонн портика при наложении совпадают. Боковая (западная) колоннада литографии на фото отсутствует: художник рисовал наискось с юго-запада, фото снято почти фронтально. Улица и фигуры не совпадают и не должны.

**Статус:** `viewpoint_review: uncertain`, требуется человек. Кроме того, для полноценной пары нужно фото, снятое с юго-западного угла площади. Это хорошая задача для режима «подсказка точки съёмки».

Итого: **0 подтверждённых пар**, 1 реальная пара-кандидат с честной частичной оценкой.

## Воспроизведение

```sh
python3 -m pip install -r tools/align/requirements.txt pytest==9.1.1
python3 -m tools.align.synthetic poc/compare/pairs          # пересоздать синтетику
python3 -m tools.align.homography poc/compare/pairs/*.json  # пересчитать H и вердикты
python3 -m pytest -q tests
python3 -m http.server 8765 --bind 127.0.0.1 &               # затем открыть http://127.0.0.1:8765/poc/compare/
NODE_PATH=$(npm root -g) node tests/browser/qa_compare.js http://127.0.0.1:8765/poc/compare/ docs/screens
```

## Почему без библиотек

Шторка, прозрачность и мерцание — это ~200 строк без зависимостей. OpenSeadragon (BSD-3) стоит подключить вместе с IIIF deep zoom уже в восстановленном приложении. Тогда фото накладывается вторым `TiledImage` с той же матрицей. Подключать img-comparison-slider — только если в старом приложении нет своего ползунка.
