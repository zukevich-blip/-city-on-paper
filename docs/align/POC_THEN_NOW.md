# Прототип «Тогда / Сейчас»: обратимое совмещение фото (Issue #6, PR B) — 01.11.2026, обновление 2

**Это независимый прототип, не выставка.** Он не трогает опубликованный сайт и не заменяет его. Когда исходник выставки восстановят (#1), просмотрщик встраивается отдельным PR (D) — в существующий код, а не вместо него.

## Правило целостности изображений

- **Историческое изображение не меняется.** В браузере у `<img>` литографии нет `transform` и `filter` — это проверяет QA-тест (и в просмотрщике, и в редакторе: там масштаб меняется только размером элемента). В репозитории файл лежит байт-в-байт таким, каким скачан (`sha256` в `pair.json` проверяется в pytest).
- **Меняется только геометрия фото, и только при показе.** Матрица 3×3 `H` (пиксели фото → пиксели литографии) применяется к фото как CSS `matrix3d`. Файл фото не пересчитывается. Кнопка «Фото: оригинал» в один клик возвращает исходный кадр, плашка «Геометрия фото скорректирована · обратимо» видна всегда. Ссылки «открыть без изменений» ведут на оба полных файла.
- Генеративное заполнение, ИИ-дорисовка и перекраска не используются.

## Вердикты

Порог — относительно диагонали исторического изображения:

| Вердикт | RMS | Худший leave-one-out | Покрытие точками | Что показывает просмотрщик |
|---|---|---|---|---|
| `high` | < 0.5 % | < 1.5 % | ≥ 15 % листа | совмещённое фото по умолчанию |
| `medium` | < 1.5 % | < 4 % | ≥ 15 % листа | совмещённое фото и предупреждение |
| `low` | — | — | или < 15 % | **по умолчанию оригинал фото**; попытка совмещения доступна по кнопке |
| `viewpoint_mismatch` | — | — | — | только оригиналы (режим «рядом»), кнопка совмещения неактивна |

Leave-one-out — это проверка параллакса. Гомография верна только для одной плоскости (фасада) или для чистого поворота камеры. Если точка, выброшенная из подгонки, плохо предсказывается остальными, значит в кадре несколько планов глубины или другая точка съёмки. Тогда честный ответ — «низкая уверенность», а не подогнанная картинка.

**Изменения после независимого ревью (обновление 2):**
1. **Горизонт.** Раньше проверялась только ориентация углов фото после преобразования, но не знак знаменателя `w = h₃₁x + h₃₂y + h₃₃`. Пример ревьюера: `H = [[1,0,0],[0,1,0],[-0.0015,0,1]]`, фото 1000×800, 8 точных точек → было `high`, хотя на двух углах `w = −0.5` (линия горизонта пересекает кадр, CSS `matrix3d` ломается). Теперь любой `w ≤ 0` в углах фото → `viewpoint_mismatch` («photo frame crosses the horizon line»). Тест добавлен.
2. **Покрытие.** Если точки охватывают < 15 % листа, вердикт не выше `low` (подгонка только локальная, зона обведена). Из-за этого Мадлен стала `low` и открывается с оригиналом фото.
3. **Безопасность просмотрщика.** Ссылки из JSON — только `http(s)://` или файлы `pairs/…` (не `javascript:`/`data:`); значения `index.json`, числа и координаты экранируются; `?mode=` проверяется по списку из 4 режимов. Есть QA-тест с «враждебным» JSON.
4. **Доступность и лицензии.** Заголовки h1 → h2 без пропусков. «Карточка» фото ведёт на страницу просмотра Panoramax (`https://api.panoramax.xyz/#focus=pic&pic=<id>`; формат проверен по коду `@panoramax/web-viewer` 5.3.1), JSON API — отдельной ссылкой. Под изображением всегда видна строка авторства с пометкой «изменения: перекодировано для удаления метаданных; совмещённый вид — производная работа (CC BY-SA 4.0)».

## Редактор контрольных точек

`poc/compare/editor.html`: загрузить пару из списка или свой JSON; при желании — свои изображения (локально, через `blob:`). Щелчок на любом изображении ставит точку, щелчок на другом — закрывает пару с номером; повторный щелчок в том же окне переставляет незавершённую точку. Перетаскивание метки двигает точку, перетаскивание по пустому месту — вид, `Ctrl`+колесо или −/+ — масштаб. Клавиатура: в окне стрелки — прокрутка, `+`/`−` — масштаб, `Enter` — точка в центр окна; на метке стрелки — 1 px (`Shift` — 10 px), `Delete` — удалить. Таблица точек показывает остатки и LOO; подписи редактируются в ней.

JS-гомография совпадает с OpenCV: для 7 точек Мадлен максимальная разница проекций **0.00002 px** (порог теста 0.5 px), на сетке по всему кадру фото — < 0.0001 px; RMS, LOO и вердикт совпадают. Для 8+ точек офлайн-инструмент может использовать RANSAC, редактор — всегда МНК по всем точкам; поэтому итог всегда считается офлайн: `python3 -m tools.align.homography файл.json`. Экспорт удаляет блок `alignment` и кладёт `editor.js_preview` для сравнения; экспорт → импорт → экспорт даёт байт-в-байт тот же JSON (проверено).

## Почему без библиотек

Шторка, прозрачность и мерцание — это ~200 строк без зависимостей. OpenSeadragon (BSD-3) стоит подключить вместе с IIIF deep zoom уже в восстановленном приложении. Тогда фото накладывается вторым `TiledImage` с той же матрицей. Подключать img-comparison-slider — только если в старом приложении нет своего ползунка.
