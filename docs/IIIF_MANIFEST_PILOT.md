# Город на бумаге: IIIF evidence gate (пилот #42)

Цель: превратить музейный IIIF Manifest в кандидата на исследовательскую карточку, без автоматической публикации и выдуманной атрибуции. Код поддерживает IIIF Presentation API v2/v3, извлекает название, формулировку прав, требуемую атрибуцию, адреса Image API и количество Canvas. Права на изображение и его подлинность самим наличием CC0/URL в Manifest не подтверждаются.

## Повторяемый запуск

1. Найти реальную запись в официальном каталоге LoC, BnF, Rijksmuseum или другого хранителя. Сохранить опубликованный учреждением IIIF Manifest (JSON) локально, записать исходный URL и дату проверки. Не генерировать идентификаторы.
2. Запустить `python -m tools.iiif.audit_manifest /path/to/official-manifest.json --output /tmp/iiif-candidates.json`.
3. Сверить `manifest_url` с карточкой учреждения, изучить `warnings`, сохранить `input_sha256`. Вручную проверить автора, роли, место, год, технику, инвентарный номер, права и правила атрибуции.
4. Перед добавлением в публичный музей отдельно проверить законность повторного воспроизведения, Image Service, CORS и мобильный zoom; при недоступности оставить ссылку на музейную запись.
5. Только проверенные данные после редакторского согласования попадают в основной каталог и публичный архив.

Скрипт работает офлайн, не обходит лимиты сервиса и не качает изображения. Каждый результат всегда содержит `publishable=false`, `status=needs_curator_review`; координаты места, позиции художника и фотографа не выдумываются.

## Критерии приёмки пилота

- Три реальных IIIF Manifest музейных произведений, с инвентарными номерами и подтверждёнными ссылками на хранителя.
- Минимум один подтверждённый Image API с глубоким масштабированием; проверка iPhone Safari и резервная ссылка на музей.
- Один исторический план, шесть и более проверяемых GCP, независимая проверка искажений через Allmaps и возможность отключить наложение.
- Десять полноценных исследовательских досье, включая отдельные поля `depicted_place`, `artist_viewpoint`, `photo_camera`, источники и степень уверенности.
- Никаких заявлений о совпадении ракурса без геометрической экспертизы.

Документация: [IIIF](https://iiif.io/api/image/3.0/), [LoC APIs](https://www.loc.gov/apis/), [Allmaps](https://docs.allmaps.org/georeference-annotations), [@allmaps/leaflet](https://allmaps.org/docs/packages/leaflet/). Связанные задачи: #39, #41, #42.
