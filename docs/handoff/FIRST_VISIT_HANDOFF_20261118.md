# Передача работы: «первый визит» — что сделано и что осталось (GPT / Codex)

Дата: 18 ноября 2026. Ветка `claude/first-visit` (PR #76, основа — `fix/fresh-verified-views` = публикация 1cb93e7).
Ничего не опубликовано этой веткой: публикация — отдельный шаг (см. «Как публиковать»).

## Решение владельца (дословный смысл)
1. Человек, который зашёл впервые, должен чувствовать интерес и понимать, куда листать дальше: **один понятный сценарий**.
2. Формулировки — простой русский, без жаргона; убрать лишний шум, добавить интересные факты, полезные любому.
3. Страница сравнения: не только «шторка». Три состояния: **литография → самое свежее фото того же ракурса → совмещение по контуру здания** («подгон под ракурс»).
4. Сохранить карты: мировые города → старые планы с нанесёнными работами → переключение на современную карту.
5. Всё в одном стиле, главы и направления связаны логикой.

## Уже сделано в этой ветке
- Главная (`index.html`): герой с переключателем «Рисунок / Фото сегодня», «Ваш маршрут» из 5 шагов, «Знаете ли вы?», остальное — в `<details class="more-museum">`.

- Карта (`eras/`): вкладки «Старая карта / Карта сегодня», простой заголовок.
- Тексты консилиума: `docs/handoff/copy-deck-20261118.json` (принципы, словарь замен ≥ 25 пар, тексты для главной, сравнения, карт, микротексты, 10 фактов с источниками).

## Правила (не нарушать)
- Историческое изображение никогда не меняется; подгоняется только современное фото, и это помечено.
- Ни одной выдуманной даты/автора/ссылки; сомнение — писать прямо («по данным…», «не установлено»).
- Не публиковать без решения владельца; не подключать платные сервисы; секреты не коммитить.
- Тесты: `pytest -q tests`, `ruff check tools tests`, браузерные `tests/browser/qa_*.js` (см. `.github/workflows/qa-city-on-paper.yml`). Если меняете структуру главной — обновляйте тесты осознанно.

## Как публиковать (после согласия владельца)
`publish-museum.yml` закрепляет ревизию и QA-run: поставить `ref` и `EXPECTED_SHA` = SHA ветки, `RUN_ID` = успешный QA-run именно этого SHA, убрать шаг overlay (он нужен только для наложения 1cb93e7 на bd5cf97), обновить проверку версии service worker, смержить в `main` → запускается деплой.
