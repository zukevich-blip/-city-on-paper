## Безусловное решение владельца

1. **Живой музей** — основной интерфейс с большой подлинной литографией, человеческой историей, следующей главой, источниками и понятной мобильной навигацией.
2. **Книга городов** — эмоциональный, но факультативный вход: книжная обложка, раскрывающаяся карта, тома/главы, режим без анимации и возможность сразу пройти в музей.
3. **Атлас времени** — отдельная исследовательская система: города/эпохи/техники, архивные оригиналы, источники, права и честная неопределённость GIS.

Не превращать всё в меню из десятков ссылок и декоративных 3D-перелистываний. Не подменять живой сайт макетами Canva.

## Сверенные факты по мировому охвату

**Срез**: подтверждённый артефакт `city-on-paper-vnext-preview` из GitHub Actions run 42833073523; входные данные датированы 4–10 ноября 2026.

- `eras/data/atlas.json`: 186 записей о географических объектах; **122** содержат `works`, **64** не содержат ни одной работы; суммарно **342** внутренних указания на произведения.
- Из 342 указаний у **163** стоит `rights_class=open`, а у **179** стоит `rights_class=link`. Право `open` в выгрузке не означает научно верифицированную атрибуцию.
- `data/curation/world-cities-v1.json`: 150 городов, преимущественно **поисковые заготовки**, не опубликованные экспозиции.
- По нормализованному русскому названию (trim + casefold) пересечение 72 названия; объединение **264 уникальные строки**. Это не 264 подтверждённых города: атлас включает, например, «Амальфи (собор)», «Вилла Адриана», отдельные замки и заливы.
- `data/curation/world-graphic-archive-v1.json`: 288 **машинно отобранных Commons-записей**, 35 названий городов, редакционная атрибуция не завершена.
- `data/curation/museum-expansion-v1.json`: 368 **машинно отобранных** предметных карточек музеев, с проверенными правами через API, но селекция по названиям; категория `city` местами содержит непредметные маркеры вроде «Город» и «Городская жизнь». Не считать это городами.
- `data/curation/modern-city-photography-v1.json`: 59 кандидатных современных фотографий, 11 городских названий; лицензии и нужные атрибуции сохранять.
- На уровне точного пересечения этих массивов найдено **156 уникальных названий** (в пределах исходных 264), к которым привязан хотя бы один `works` или машинно найденный кандидат; ещё **108** без записей этих типов. Это оценка по доступным массивам, **не гарантирует редакционное покрытие** и может отличаться от заявления Claude «160».
- В детальном `eras/data/eras.json` представлены **три** тщательно оформленных города: Париж, Флоренция, Неаполь.
- **Санкт-Петербург** присутствует в списках, но в `eras/data/atlas.json` у него ноль работ. Москва (14), Рим (34), Париж (77) имеют работы в атласном списке, однако полнота и статус проверки отличны от нового детального каталога.
- Ещё одна серьёзная ошибка структуры: `kind` в 186 объектах равен `monument` для 46, `landscape` для 8, `town` для 41, `city` для 27 и отсутствует для 64. Нельзя все записи отображать как города. Нужна нормализованная сущность **город → место/объект → произведение**.

## Что требуется от Claude/Codex после возобновления

### P0 — фактический мировой индекс
Сделать воспроизводимую сборку нормализованного `city_id` с RU/EN/альтернативными именами, страной, типом сущности и записью источника; разделить **city, town, monument, landscape**. Отдельно хранить статусы `seed_only`, `candidate_found`, `archive_verified`, `curated_story`, не перемешивать проверку лицензии и правдивость сюжета. Дедупликация по названию без страны недостаточна, потому что в мире есть одноимённые города.

### P1 — готовая публичная структура (без публикации)
Сделать «Города мира» как полноценный удобный раздел со странами, регионами, поиском и фильтром по степени наполнения, 10–15 действительно сильными городскими страницами по мере появления открытых проверенных работ. **Пустые страницы должны быть честно помечены**, не заполнять искусственными файлами.

### P1 — визуальное качество
Единая музейная антиква и гротеск, цвета `#F4EFE5 #29463D #292D29 #B79567 #88513B`. Сначала большой подлинник и рассказ, а не сложный пульт. Задачи по мобильной верстке: iPhone 320/390px, tablet 820px, desktop 1440px, кликабельные зоны ≥44px, клавиатура, тихий режим.

### P1 — производительность
Не путать вес **скачиваемого исследовательского ZIP** (280+ MB) с реальным весом **первого HTTP-экрана**; измерить то и другое отдельно. Ленивые миниатюры/карты, ограничение одновременной загрузки, лёгкий индекс, динамические разделы, Lighthouse/Core Web Vitals по факту замеров, не выдумывать LCP/INP/CLS.

### P2 — рост коллекции и контента
Приоритетная реальная кураторская программа: Париж, Флоренция, Неаполь, Венеция, Рим, Лондон, Санкт-Петербург, Москва, Прага, Стамбул, плюс города Азии, Америки, Африки и Океании. У каждого листа: `museum / original_url / creator_roles / title / date / technique / rights / license / source_checked_at / review_status / depicted_place_confidence`. Начать с самых сильных 10–15, но не фабриковать материалы.
