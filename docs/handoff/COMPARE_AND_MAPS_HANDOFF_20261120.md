# Задание: совмещение старого и нового, контуры зданий, карты

Дата: 20 ноября 2026. Ветка: `claude/consilium-wander` (PR №85, черновик). Публикацию на основной сайт согласует владелец отдельно.

## Что уже есть в ветке

- `poc/compare/index.html`: переключатель «Тогда · Сейчас · Переход · Совместить · Шторка». «Переход» — плавная прозрачность без подгонки, «Совместить» — подгонка фото по гомографии `pair.alignment.H` с границей области (`valid_region_historic`), «Шторка» — две исходные картинки.
- `poc/compare/editor.html`: ручная настройка (точки на рисунке и фото). Точки сохраняются в `localStorage` под ключом `cop-manual-<id пары>`, страница сравнения применяет их и показывает «Вернуть как было».
- `eras/maps.js`: на карте мира вкладка «Наложение»: старая карта Европы 1769 года поверх современной с ползунком. Привязка считается в браузере по городам (`xy` в пикселях ↔ `lat/lon`), средняя ошибка около 110 км. Это честно подписано.
- В `poc/compare/pairs/index.json` 13 пар, в маршруте 6 сцен.

## Что просит владелец (приоритет сверху вниз)

1. **Контур здания для каждой пары.** Показывать обведённый главный объект на обоих изображениях (переключатель «Контур»). Где совмещение невозможно (разные стороны съёмки), контур всё равно рисуется отдельно на рисунке и на фото, без наложения. Данные: поле `building_outline: {historic: [[x,y],...], photo: [[x,y],...]}` в JSON пары. Точки ставить по реальным деталям (углы фасада, карниз, основание колонн), проверять глазами по скриншотам, не по памяти.
2. **Больше пар.** Сейчас только 13 и 6 в маршруте. Нужны пары для Рима, Парижа, Флоренции, Венеции, Петербурга, Лондона. Исходные листы брать из уже проверенных данных (`data/curation/*`, `eras/data/atlas.json`), а не из памяти.
3. **Несколько современных фото на пару.** Свежее (для «сегодня») и ближайшее по ракурсу (для сравнения). Год съёмки виден рядом с кадром (уже показывается для текущего фото). Источники: Wikimedia Commons (с контейнера Claude отвечает 429, нужен другой IP), Panoramax (`api.panoramax.xyz`, работает). У каждого фото: автор, лицензия, дата съёмки (EXIF), ссылка.
4. **«Где стоял художник?»** Старая и современная карты, стрелка направления взгляда, ориентиры. Для Пантеона и Мадлен нужны координаты точки художника как оценка с пометкой «оценка» и объяснением, как получена. Не выдумывать числа.
5. **Карты: старое и новое.**
   - Наложение планов городов (Париж 1878: `eras/img/loc-2012586603-paris-1878.jpg`) на современную карту с ползунком. Нужны контрольные точки (улицы, мосты), привязка проверяется на визуальном совпадении и честно подписывается погрешностью.
   - Для других городов искать открытые планы с известными правами (LoC, Gallica, David Rumsey с открытой лицензией) и подключать тем же механизмом (`mixFit` в `eras/maps.js` можно обобщить).
   - Связка «город мира → лист → старая карта с нанесёнными видами → современная карта» должна оставаться одним путём.
6. **Прозрачность и подгонка друг к другу** — для карт и для литографий в одном стиле управления (один ползунок, понятные подписи, телефон).

## Правила

- Не деформировать литографию. Подгоняется только современное фото или современная карта.
- Не отмечать непроверенную пару как «идеальную». Для разных точек съёмки честно писать, что наложение невозможно.
- Права: CC0, CC BY, CC BY-SA, «ограничений не известно» (LoC). У каждой картинки автор, дата, лицензия, ссылка.
- Простой русский: без «RMS», «LOO», «гомография» в видимом тексте. Технические подробности в раскладках «Для специалистов».
- Проверки перед PR: `pytest -q tests`, `ruff check tools tests`, `tests/browser/qa_compare.js`, `qa_guides.js`, `qa_eras.js`, `qa_first_impression.js`. Телефон: 390 px, без горизонтальной прокрутки, кнопки не менее 44 px.
- Публикацию на основной сайт без разрешения владельца не делать.
