# Информационная архитектура и 3 визуальных направления (Issue #6, PR C) — 01.11.2026

**Только предложение для выбора стиля.** Это не реализация и не замена выставки. Окончательный стиль выбирает владелец, после чего он переносится в **восстановленный** исходник выставки (#1).

```

│
├── Главная
│   ├── Выставка недели (1 работа, без эффектов, кредит под изображением)

├── Маршрут «Прогулка во времени»
```

## 2. Три направления (одно содержание, разный стиль)

Все три макета собираются из одной модели контента: `docs/ux/mockups/build.py`.

| | A · Архивная бумага | B · Ночной атлас | C · Путевой дневник и кухня |
|---|---|---|---|
| Идея | музейный каталог, паспарту, антиква | карта прежде всего, спутник путешественника | редакционный журнал, кухня и улица на первом экране |
| Сильные стороны | бережно к литографии; хорошо для каталога | маршруты и точки съёмки; удобно на улице | вовлекает; естественно для рубрики «Жизнь на площади» |
| Риски | может казаться «пыльным» | тёмный фон меняет восприятие цвета раскрашенной литографии (светлая тема обязательна) | крупные заголовки отнимают место у изображения |
| Макет | `mockups/a-archive.html` | `mockups/b-atlas.html` | `mockups/c-journal.html` |
| Снимки | `screens/a-archive-{390,1440}.jpg` | `screens/b-atlas-{390,1440}.jpg` | `screens/c-journal-{390,1440}.jpg` |

**Рекомендация Claude:** **A** — для страниц работы и каталога; элементы **B** (карта и маршрут) — для городов и прогулок; рубрику из **C** — внутри A, без отдельного стиля. Иначе говоря, один спокойный «бумажный» стиль и тёмная тема как опция, а не как основа.

## 3. Правила, которые соблюдены в макетах

- Изображения:
  - только две литографии Ph. Benoist из Library of Congress («No known restrictions on publication», LC-DIG-pga-14315 и -14314);
  - файлы байт-в-байт: sha256 `ad6ec25a…` и `56114d4d…`;
  - показ `object-fit: contain` — без кадрирования, фильтров и перекраски.
- Записи BnF (NoC-OKLR) и другие `restricted` показаны **карточкой-ссылкой без изображения**.
- Нет сгенерированной или «декоративной» графики, выдаваемой за подлинную. «Бумажность» создаётся только цветом интерфейса, а не текстурами поверх работ.
- Карта — заглушка без тайлов. В реализации: Leaflet и тайлы с открытой лицензией, с атрибуцией.
- Проверка: нет горизонтальной прокрутки на 390 и 1440 px (Playwright, 01.11.2026). Элементы-фасеты ≥ 44 px.
