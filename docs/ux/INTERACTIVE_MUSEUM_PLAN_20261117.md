# Город на бумаге — интерактивный вход и следующая музейная ревизия
Дата: 17.11.2026 · Источник проверки: `bd5cf97b` (16.11.2026), тексты проекта, QA 43908032492 и переписка фототеки Hertziana от 16.11.2026.

## Что уже работает и что не трогаем

Текущая версия имеет два реальных изображения Мадлен с датами, шторку/«рядом», интерактивные карты, Салон с индивидуальными историями, городские маршруты, бесплатные QA и лёгкие изображения для первых экранов. Счётчик в релизе заявляет 61 город и 820 LoC изображений. Исходный исследовательский массив содержит 827 записей в 63 городах; это **не 827 литографий**: там есть фотохромы и другие виды. Полнота атрибуции не равна числу записей.

**Не менять без отдельной проверки:** исходные архивные изображения, ссылки хранителей, названия и даты произведений, карту-объект vs точку наблюдения, существующие выставки и общую публикацию GitHub Pages.

## Путь первого посетителя

1. До чтения длинных текстов он видит подлинные изображения XIX и XXI веков.
2. Трогает переключатель «Рядом / XIX век / Сегодня», без регистрации, анимационного обмана и скачивания новых данных.
3. Получает вопрос по подписи листа: «Imp. Lemercier» — художник или печатная мастерская?
4. Проверяет ответ по карточке Library of Congress, затем выбирает один из четырёх существующих музейных маршрутов.

Это добавлено в отдельной тестовой ветке, не в опубликованном сайте. При выключенном JavaScript остаётся текущая пара изображений и ссылки.

## Следующие **отдельные** интерактивные эксперименты

**P1: «Что исчезло?» — исторический след.** На одном проверенном изображении накладываются кнопки-подсказки, открывающие сведения о судьбе здания (фотографии/текст из публичного источника). Первый научно достоверный пример — Тюильри: пожар 1871, руины в 1878, снос к 1883. Лишь с проверенной привязкой к изображению. Не писать, что координата здания = точка художника.

**P1: «Мастерская литографа» — 4 решения посетителя.** Рисунок, камень, печать, раскрашивание; реагирующие карточки без видео и платных сервисов. Показывать роли художника, литографа, печатника и издателя; не приписывать печать художнику. Завершение ведёт к историческому экземпляру.

**P1: «Найдите тот же фасад».** Два соседних документальных изображения с самостоятельными масштабами. Посетитель отмечает одну опознаваемую деталь; система объясняет отличие ракурсов. Совпадение НЕ означает доказанной камеры или пиксельной геометрии. Отключить «шторку с наложением», если совпадение ракурса не подтверждено.

**P2: «Лист → исторический план → современная улица».** Одно прикосновение переносит посетителя между объектом, картой периода, карточкой источника и современным снимком. На карте подписывать точность геопривязки и состояние исчезнувшего объекта на выбранный год.

**P2: «Фотоохота».** Посетитель загружает снимок на своём устройстве, выбирает примерный ракурс, сравнивает с листом. Фото остаётся локальным; никаких обещаний общей публикации и автоматического подтверждения камеры.

**P2: «Путешествие по листам Бенуа в Риме».** Разрешённые фототекой уменьшенные **неизменённые** изображения с подписью и ссылкой на оригинал; история места, участники изготовления и контекст альбома. Пилот на 3 тщательно проверенных листах, затем расширение до утверждённого набора.

## Лицензия Rome dans sa grandeur — не смешивать с CC

Персональное письменное разрешение Bibliotheca Hertziana (16.11.2026) распространяется на запрошенные некоммерческие веб-миниатюры до 1000px двух записей `obj08003573`, `obj08003574` (40 листов в запросе). Обязательный кредит: **Bibliotheca Hertziana (Max Planck Institute for Art History), Rome**. Источник — приватная переписка хранится у владельца, текст письма в репозиторий не загружать. Поэтому **не использовать эти фото в промо на главной, в AI-роликах или в шторках с геометрическим искажением**. Публикация миниатюр после проверки исходных файлов, идентификаторов и при необходимости подтверждения применимых общих условий. Статус `In Copyright` сохраняется.

## Контроль качества и скорости

- 320/390/820/1440px: нет горизонтального скролла и спрятанных кнопок, реальная фотография/литография загружаются и имеют корректные подписи.
- Все режимы обратимы, каждая кнопка — `<button>` с `aria-pressed`; есть видимый фокус и `prefers-reduced-motion`.
- Одно новое действие максимум за один клик; не вводить обязательные интро, формы и регистрацию.
- Никаких тяжёлых фреймворков и новых внешних API на первом экране. Новая микрофункция использует уже загруженные изображения, JavaScript около 2KB и CSS около 3KB до сжатия.
- Дата сюжета, дата изготовления листа и состояние здания на год карты — независимые поля.
- Задачи публикации не должны пересобирать сотни мегабайт изображений при изменении только текста; исследовать кэширование и привязку артефактов как отдельный безопасный этап.
- В одном из релизных коммитов в `main` оказались отслеживаемые `.pyc` и файлы состояния сбора. Завести отдельную проверку репозитория и исключить их из будущих релизов без удаления ценных исходников.
- После CodeRabbit уведомления не считать проект прошедшим review, если в письме сказано «Review skipped» или «Currently processing». Финальным доказательством служат CI, независимые визуальные снимки и ручная проверка.

Приоритеты в этом PR: **интерактивный вход + область прав + автоматические тесты**. Всё остальное — очередь самостоятельных экспериментов, не причина переписывать работающий музей.
